# Critic Agent Memory

## このプロジェクトで見落としやすいリスク

- **Changelog の数値記述**: コードのデフォルト値（`:-500` 等）と Changelog 記載値の乖離が発生しやすい。レビュー時は必ずコードの実際の値と照合する
- **バージョン間の連続性チェック**: 前バージョンの Changelog と現バージョンで同じパラメータが異なる値で言及される場合、どちらが正かコードで確認する
- **diff テキストの文字化け**: 差分データに壊れた文字列が混入することがある。適用後の README を直接確認する

## 計画品質の判定基準

- FR（機能要件）が実装に反映されているか: 挿入位置・除外対象の明確な指定は必須
- 数値・固有名詞は必ずコードと照合（楽観的に「記述通り」と通過させない）
