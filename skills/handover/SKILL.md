# セッション引き継ぎノート生成

セッション終了時に HANDOVER.md を生成し、次のセッションへ文脈を引き継ぐ。

## 手順

1. 今回のセッションで行ったことを振り返る
2. 以下の構成で HANDOVER.md をプロジェクトルートに生成する
3. 既に HANDOVER.md が存在する場合は上書きする（前回分は不要）

## HANDOVER.md の構成

必ず以下のセクションを含める:

### 目標
このセッションで達成しようとしていたこと（1-2行）

### 完了した作業
作業内容と進捗を箇条書きで

### 未完了の作業
残っている作業と、どこまで進んだか

### 決定事項
確定した設計判断、方針、ルールなど

### 捨てた選択肢と理由
検討したが採用しなかったアプローチとその理由

### 既知の問題・注意点
バグ、ワークアラウンド、ハマりポイント

### 次のステップ
次のセッションで最初にやるべきこと（優先順位付き）

### 変更ファイルマップ
変更したファイルと各ファイルの変更概要

## ルール

- **簡潔に**: 各セクション 3-5 行以内
- **使い捨て**: HANDOVER.md は次のセッションで上書きされる前提
- **知識は memory に**: 長期的に価値のある知見は auto-memory に任せる。HANDOVER.md には session state のみ
- **VCS 管理しない**: .gitignore に含まれる
