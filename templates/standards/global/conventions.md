# Conventions

プロジェクト全体で守るべき規約を定義します。

## Git

- コミットメッセージ: Conventional Commits
  - `feat:` 新機能
  - `fix:` バグ修正
  - `docs:` ドキュメント
  - `refactor:` リファクタリング
  - `test:` テスト
  - `chore:` その他

## ブランチ戦略

- `main` - 本番環境
- `develop` - 開発環境
- `feature/*` - 機能開発
- `fix/*` - バグ修正

## エラーハンドリング

- 例外は適切な粒度でキャッチ
- ログレベルを適切に使い分ける
- ユーザー向けエラーメッセージは具体的に

## セキュリティ

- シークレットはコードにハードコードしない
- 入力値は必ずバリデーション
- SQLインジェクション、XSS対策を実施
