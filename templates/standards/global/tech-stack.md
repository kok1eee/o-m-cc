# Tech Stack

プロジェクトで使用する技術スタックを定義します。
**このファイルはプロジェクトに合わせて編集してください。**

## 言語・ランタイム

- 言語: TypeScript / Python / Go など
- ランタイム: Node.js / Bun / Python 3.x など

## フレームワーク

- フロントエンド: React / Vue / Svelte など
- バックエンド: Express / FastAPI / Gin など
- ORM: Prisma / SQLAlchemy / GORM など

## データベース

- メイン: PostgreSQL / MySQL / SQLite など
- キャッシュ: Redis など

## インフラ

- ホスティング: AWS / GCP / Vercel など
- CI/CD: GitHub Actions など

## 開発ツール

- パッケージマネージャ: npm / pnpm / uv など
- リンター: ESLint / Ruff など
- フォーマッタ: Prettier / Black など
- テスト: Vitest / pytest など
