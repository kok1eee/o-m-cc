# Vision Formats Reference

> このファイルは `agents/vision.md` から段階的開示（Progressive Disclosure）で分離されたリファレンスです。
> エージェント実行時に `Read` して適用してください。

## 画像分析フォーマット

```markdown
# 画像分析: [ファイル名]

## 概要
[画像の種類と内容の概要]

## 抽出した情報

### テキスト内容
[画像内のテキスト]

### 構造
[UI構造、レイアウト等]

### 重要なポイント
- [ポイント1]
- [ポイント2]

## 技術的な洞察
[実装に役立つ情報]

## 次のアクション
[この情報をどう活用するか]
```

## PDF分析フォーマット

```markdown
# PDF分析: [ファイル名]

## ドキュメント概要
- **ページ数**:
- **種類**: [仕様書/マニュアル/論文等]
- **作成日**:

## 目次/構成
1. [セクション1]
2. [セクション2]

## 要約
[3-5文で内容を要約]

## 抽出した要件/仕様
- [要件1]
- [要件2]

## 表・図
[重要な表や図の説明]

## キーポイント
[実装・判断に重要な情報]
```
