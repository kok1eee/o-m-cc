# ADR-0006: 品質保証を3層構造にする

- Status: accepted
- Date: 2025-03-10

## Context

Sisyphus Loop は「品質が維持される限り止まらない」が原則。品質チェックが足りなければ壊れたまま走り続け、多すぎれば不必要に止まる。LLM 依存のチェックは不安定な場合があり、LLM 非依存のチェックだけでは内容の妥当性を判断できない。

## Decision

3層構造で品質を保証する。各層は異なる観点と信頼度を持つ。

| 層 | 仕組み | LLM 依存 |
|---|---|---|
| Layer 1 | 形式チェック（`validate-plan`）: 必須セクション・FR 言及率を自動検証 | なし |
| Layer 2 | CTA（sisyphus SKILL.md）: 元の要求との内容乖離を LLM が判断 | あり |

## Consequences

- **良い面**: LLM 依存と非依存のチェックを組み合わせることで、形式的な漏れと内容的な乖離の両方を検出できる。各層が独立しているので個別にチューニング可能
- **悪い面**: 3層あることで複雑さが増す。Layer 2 は LLM の判断精度に左右される。層間の役割分担が曖昧になると重複チェックが発生する
