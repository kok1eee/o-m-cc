# ADR-0003: Progressive Disclosure でトークン消費を最小化する

- Status: accepted
- Date: 2025-03-01

## Context

Claude Code のエージェント・スキルは、定義ファイルの内容がコンテキストウィンドウに読み込まれる。定義が長いほどトークンを消費し、コストと応答速度に影響する。一方で、エージェントが正しく動作するには十分な情報が必要。

## Decision

3段階の Progressive Disclosure で情報を段階的に開示する。

1. **frontmatter**: エージェントの名前・説明・ツール一覧（常にロード）
2. **本文**: エージェントのシステムプロンプト（起動時にロード）
3. **参照ファイル（facets/）**: 共通ポリシー・詳細リファレンス（エージェントが必要時に Read）

## Consequences

- **良い面**: 必要な時に必要な情報だけロードされる。エージェント定義が肥大化しない。共通ポリシー（Confidence Scoring 等）を facets/ で一元管理できる
- **悪い面**: エージェントが参照ファイルの Read を忘れると情報不足になる。ファイル間の依存関係が暗黙的
